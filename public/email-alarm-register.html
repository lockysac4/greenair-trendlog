Alarm Email Behaviour

An email is sent when an alarm changes from 0 to 1. The same active alarm is not repeatedly emailed while it remains at 1. When the register returns from 1 to 0, a CLEARED email is sent. Alarm notification state is stored in PostgreSQL so a Render restart does not resend an alarm that has already been notified.
